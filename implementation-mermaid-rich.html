Updated Architecture

Rich Mermaid view of the current design: Telegram uses one persistent main session, /new swaps that main session, and cron jobs now choose between following the current main session or running in isolated detached sessions.

Key behavior

  • Manual chat always uses the current Telegram-bound main session.
  • /new creates a new session and rebinds the chat to it.
  • target: "main-session" cron jobs follow the current binding automatically.
  • target: "detached" cron jobs run in a fresh disposable session.
  • Approval policy and reminder command flow were removed from runtime.
